# 📌 Task Management API

## 📖 Overview
The **Task Management API** is a Spring Boot application that allows users to efficiently manage tasks. It supports:
- ✅ Task creation, updating, and deletion
- ✅ Task prioritization and status tracking
- ✅ Multi-user support
- ✅ Secure access with user authentication

## 🛠️ Technologies Used
- **Java 17**
- **Spring Boot **
- **Spring Data JPA**
- **PostgreSQL (or MySQL)**
- **Spring Security**
- **JWT Authentication**
- **Lombok**

## 🚀 Features
- 📌 **User Management**: Register and authenticate users
- 📌 **Task Management**: Create, update, delete, and assign tasks
- 📌 **Task Prioritization**: Categorize tasks as **LOW, MEDIUM, HIGH**
- 📌 **Status Tracking**: Set task status as **PENDING, IN_PROGRESS, COMPLETED**
- 📌 **Secure API**: Protect routes with authentication
